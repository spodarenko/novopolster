If the user invokes this skill without any other guidance, ask them what they want to build or design, ask some questions, and act as an expert designer who outputs HTML artifacts _or_ production code, depending on the need.

Key things to remember about this brand:
- Two-tone identity only: brand teal `#0CA194` + ink `#131413`. No third accent color.
- Typography: Golos Text (display + body), loaded with Latin + Cyrillic subsets — the site is DE/EN/UA/IT multilingual and Ukrainian copy must never fall back to a system font.
- The core brand promise is transparent from–to pricing shown upfront — never write "price on request" copy or hide a price behind a form.
- WhatsApp is the primary contact channel — lead with it before phone/email/contact forms.
- Crisp corners (4–20px), warm-tinted low-opacity shadows, hairline borders doing most of the separation work — avoid bubbly/rounded-everything AI-slop defaults.
- No logo file exists for a generated mark — only the one supplied lockup was ever provided. Never redraw or invent a new logo; reuse the assets in `assets/logo/`.
