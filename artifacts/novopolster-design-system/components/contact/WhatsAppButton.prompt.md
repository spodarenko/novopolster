The brand's primary contact channel — used instead of leading with a phone number or contact form, and reads naturally in all four site languages.

```jsx
<WhatsAppButton phone="4989123456" message="Hallo, ich interessiere mich für eine Sofa-Reinigung." />
<WhatsAppButton floating={false} label="Jetzt chatten" />
```

`floating` (default `true`) renders a fixed circular button bottom-right, present on every page. Set `false` for an inline pill CTA inside the hero or contact section.
