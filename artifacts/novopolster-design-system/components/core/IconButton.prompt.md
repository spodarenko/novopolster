Circular icon-only button for the sticky WhatsApp float, header phone shortcut, and any control that doesn't need a text label.

```jsx
<IconButton icon="assets/icons/phone.svg" label="Anrufen" variant="outline" />
```

Variants: `primary` (brand fill), `outline` (default — white with border), `ink` (near-black fill, for dark sections). Sizes `sm`/`md`/`lg` — `lg` (56px) is the minimum touch target for the floating WhatsApp button.
