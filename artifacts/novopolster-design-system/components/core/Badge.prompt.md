Small pill label for service tags, trust badges and language pills.

```jsx
<Badge tone="brand" icon="assets/icons/shield-check.svg">Festpreis-Garantie</Badge>
```

Tones: `neutral` (default, low-emphasis tag), `brand` (teal-tinted, for USPs like "Festpreis"), `ink` (solid dark, on photo overlays), `success` (confirmations).
